# SEC Filing Document Copilot

An enterprise-grade, pilot-ready AI copilot for financial research analysts to query SEC Form 10-K filings with **strict verbatim citation grounding**, hybrid retrieval (dense vector embeddings + sparse full-text search with Reciprocal Rank Fusion), and an interactive Trust UI.

Designed and optimized to run **100% within free tiers ($0.00 infrastructure cost)**.

---

## Key Features

- **Strict Verbatim Grounding**: Every claim generated by the assistant is tied to a citation chip backed by an exact substring match from SEC 10-K passages. No hallucinations.
- **Hybrid Retrieval (RRF)**: Combines 768-dimensional `gemini-embedding-2` vector similarity (`pgvector` with HNSW indexing) and PostgreSQL `tsvector` full-text search fused using Reciprocal Rank Fusion ($k=60$).
- **Optimized Free-Tier Pipeline**:
  - Local heuristic keyword extractor with financial stopword filtering (0 API calls).
  - In-memory `@lru_cache` query embedding layer.
  - Direct grounded single-turn synthesis (1 LLM call per turn).
  - Capacity: 750 to 1,500 questions/day on Google AI Studio's free tier.
- **Interactive Trust UI**:
  - Verbatim citation chips with click-to-inspect drawers.
  - Source Passage Inspector with `±1 Chunk` context expander to read adjacent 10-K paragraphs.
  - Real-time pulsating pipeline status indicator during retrieval and synthesis.
- **Multi-Tenant Architecture**: Thread-isolated chat persistence with PostgreSQL and Supabase.

## Quickstart: Running Locally

### Prerequisites
- **Python**: Version 3.12+ ([uv recommended](https://docs.astral.sh/uv/))
- **Node.js**: Version 18+ and `pnpm` (or `npm`)
- **Supabase**: Free Supabase project with `pgvector` extension enabled
- **Google Gemini API Key**: Free API key from [Google AI Studio](https://aistudio.google.com/)

---

### Step 1: Clone and Configure Environment

#### Backend Environment (`backend/.env`)
Copy `backend/.env.example` to `backend/.env` (or create `backend/.env`):

```env
# Supabase Configuration
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# PostgreSQL Database Connection String (Direct Connection)
DATABASE_URL=postgresql://postgres.your-project-id:your_password@aws-0-region.pooler.supabase.com:5432/postgres

# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key
GEMINI_CHAT_MODEL=gemini-2.5-flash
GEMINI_EMBEDDING_MODEL=gemini-embedding-2
GEMINI_EMBEDDING_DIMENSIONS=768

# Allowed CORS Origins (comma-separated)
ALLOWED_ORIGINS=http://localhost:5173,http://localhost:5174
```

#### Frontend Environment (`frontend/.env`)
Create `frontend/.env`:
```env
VITE_API_URL=http://localhost:8000
```

---

### Step 2: Database Migration

Navigate to the `backend` directory and run database migrations to set up the schema and indexes:

```bash
cd backend
uv run alembic upgrade head
```

---

### Step 3: Launch Backend

From the `backend` directory:
```bash
uv run uvicorn app.main:app --reload --port 8000
```
The FastAPI backend will be live at `http://127.0.0.1:8000`. You can inspect interactive OpenAPI documentation at `http://127.0.0.1:8000/docs`.

---

### Step 4: Launch Frontend

Open a new terminal window, navigate to the `frontend` directory:

```bash
cd frontend
pnpm install
pnpm dev
```
The web application will be live at `http://localhost:5173`.

## SEC Filing Ingestion Guide

The platform includes scripts to download SEC EDGAR filings, convert them to clean Markdown, and ingest them into Supabase with vector embeddings.

### 1. Ingest Filings into Database
To parse, chunk, and embed a specific filing (e.g. Apple 2024 Form 10-K):
```bash
# Run from repository root
uv run --directory backend python -m data.ingest.cli --ticker AAPL --year 2024 --write --embed --replace
```

Available flags:
- `--ticker`: Stock symbol (`AAPL`, `MSFT`, `NVDA`, `AMZN`, `GOOGL`).
- `--year`: Filing fiscal year (`2024`, `2023`).
- `--chunk-limit`: Limit chunks for rapid testing (e.g. `--chunk-limit 50`).
- `--write`: Commit documents and chunks to Supabase.
- `--embed`: Generate 768-dimensional Gemini vector embeddings.
- `--replace`: Overwrite existing chunks for this filing.
